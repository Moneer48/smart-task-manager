# Smart Task Manager

A command-line task management application built in Kotlin to practice core Object-Oriented Programming (OOP) concepts.

## Features
- **Task Management:** Create, view, update, and delete tasks.
- **Priority & Status:** Categorize tasks and track execution status.
- **Console Interface:** Interactive terminal interface for user inputs.

## Technologies Used
- **Language:** Kotlin
- **Tools:** IntelliJ IDEA / Command Line
